# Starter Infinity Chest

Starts each new player in freeplay with one one-use infinity chest for choosing their preferred starting supplies without changing any other gameplay values.

## Features

- Gives each newly created freeplay player one Starter infinity chest.
- Reuses the vanilla infinity chest interface for choosing items, quantities, and quality-aware filters when available.
- The chest can be mined and moved freely before it is first opened.
- Once opened, the chest becomes non-minable; closing its interface destroys it permanently.
- Does not alter technologies, recipes, resources, equipment, robots, enemies, or other vanilla balance values.
- Uses the vanilla infinity chest graphics and interface; no custom gameplay assets are required.

## Usage

1. Place the Starter infinity chest wherever you want to prepare your starting supplies.
2. Open it and configure the vanilla infinity filters for the items you want.
3. Take everything you need before closing the interface.
4. Close the interface. The chest is permanently destroyed.

**Warning:** Closing the chest interface after its first opening is final.

## Compatibility

- **Required:** Factorio 2.1.
- **Space Age:** Optional.
- **Quality:** Optional. When enabled, the vanilla infinity chest supports quality-aware filters.
- Each new player receives their own chest in freeplay, including non-admin multiplayer players.
- Adding the mod to an existing save does not retroactively grant a chest to players who already exist.

## Localization
